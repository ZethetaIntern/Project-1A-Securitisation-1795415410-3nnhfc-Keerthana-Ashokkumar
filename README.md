# Securitisation Risk Assessment – Project 1A

Auto-loan ABS pool **ZAAUTO2024-1** (500 loans, cut-off: 31 October 2024).

This project covers end-to-end securitisation risk analysis, including data auditing, delinquency and vintage analytics, IFRS 9 Expected Credit Loss (ECL), cash flow waterfall, stress testing, Power BI reporting, and investor analysis.

## Project Scope

- Loan portfolio data analysis
- Data quality checks and audit
- Delinquency and DPD analysis
- Static pool and vintage analysis
- IFRS 9 Expected Credit Loss (ECL)
- Cash flow waterfall analysis
- Credit enhancement and stress testing
- Power BI dashboard and DAX measures
- Investor reporting

## Tools & Technologies

- Microsoft Excel
- Power BI
- DAX
- Python
- Pandas
- Git & GitHub

## Dataset

The project uses four datasets:

- Auto Loan Securitisation Data
- DPD Snapshot History
- Static Pool Vintage Data
- Dynamic Loss Monthly Data
